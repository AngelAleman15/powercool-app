# Proyecto

PowerCool es una plataforma SaaS para administrar servicios de climatización. Su interfaz debe ser limpia, moderna y profesional.

## Tecnologías

- React / Next.js
- TypeScript
- Tailwind CSS
- Firebase y Supabase existentes

## Reglas de trabajo

- Entender el contexto y cambiar únicamente lo necesario.
- No refactorizar código ajeno a la tarea ni modificar lógica, Firebase o API sin solicitud expresa.
- Reutilizar componentes, hooks y utilidades existentes antes de crear otros.
- Usar Tailwind; conservar compatibilidad de escritorio y móvil.
- Preferir funciones pequeñas, nombres claros, componentes reutilizables y tipado estricto. Evitar `any`, duplicación y componentes gigantes.

## Diseño

- Buscar una estética SaaS premium: espacio en blanco, jerarquía visual, bordes redondeados, sombras suaves, pocos colores, tipografía e iconografía consistentes.
- Evitar interfaces recargadas, tarjetas cuadradas y colores saturados.
- La versión móvil debe sentirse diseñada para móvil, no una reducción de escritorio.

## Rediseños

- Modificar solo layout, espaciado, tipografía, iconos, colores y componentes visuales.
- No modificar lógica, Firebase ni API.

## Antes de terminar

- Verificar TypeScript, respuesta móvil, dark mode cuando aplique y accesibilidad básica.
- Analizar solo los archivos necesarios.
